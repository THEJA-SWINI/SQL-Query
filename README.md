# SQL-Query
Part 1 – Constraints
Choose any real-world scenario and create at least 2 related tables.
Apply appropriate constraints such as:
PRIMARY KEY
FOREIGN KEY
NOT NULL
UNIQUE
DEFAULT
CHECK
Insert suitable sample records into your tables.

Part 2 – Joins
Using your tables, write queries to demonstrate:
INNER JOIN
LEFT JOIN
RIGHT JOIN
FULL OUTER JOIN 

For each join, display relevant columns from both tables.


Part 3 – Query Practice
Write queries to:
Display records by combining data from both tables.
Display all records from the first table, including records that don't have a matching record in the second table.
Display all records from the second table, including records that don't have a matching record in the first table.
Find records based on a specific condition using a JOIN.
Try inserting invalid data to observe how the applied constraints work.
